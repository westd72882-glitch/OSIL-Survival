# Как поднять свой сервер OSIL Survival

Гайд по шагам. Три способа: на VPS, на своём компьютере (для игры по локальной сети) и
на render.com — в один клик из этого репозитория. Работают все три: https игра открывает
системными средствами, поэтому облачный адрес вводится прямо в меню.

---

## Что вообще происходит

Мир на сервере и в игре строится из одного и того же сида (`osil`), поэтому по сети
ездят не куски карты, а только игроки и правки мира: кто где стоит, куда смотрит, что
построил и что срубил. Обмен — обычный HTTP, десять раз в секунду.

Из этого следует главное: **сид на сервере и в игре должен совпадать**. В
`config/server.cfg` уже стоит `world.seed = osil` — тот же, что и в клиенте. Менять его
можно, но тогда менять придётся и в игре (пересборкой клиента), иначе постройки окажутся
не в том месте, где их видят остальные.

---

## Способ 1. VPS — так играют с друзьями через интернет

Подойдёт любая машина с Linux: Timeweb, Selectel, Hetzner, Oracle Cloud (у него есть
бесплатный тариф). Нужен самый дешёвый тариф: серверу хватает одного ядра и 512 МБ.

### 1. Поставить инструменты

```sh
sudo apt update
sudo apt install -y git g++ cmake make
```

### 2. Забрать исходники и собрать только сервер

```sh
git clone https://github.com/westd72882-glitch/OSIL-Survival.git
cd OSIL-Survival
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --target osil_server -j"$(nproc)"
```

Собирается только сервер — SDL, OpenGL и прочая графика ему не нужны, поэтому сборка
идёт минуту и работает на голой машине без иксов.

### 3. Настроить

Открыть `config/server.cfg` и поправить две строки:

```
server.hostname   = "[RU] Мой сервер"
server.maxplayers = 20
```

Порт по умолчанию 28015. Если хочется другой — `server.port = 30000`.

### 4. Запустить

```sh
./build/bin/osil_server
```

В логе появится:

```
сеть: сервер «[RU] Мой сервер» ждёт игроков на порту 28015
```

Проверить, что живой, можно прямо из браузера — откройте `http://АДРЕС:28015/`, сервер
отдаст свою карточку:

```json
{"name":"[RU] Мой сервер","map":"Survival Island","players":0,"max":20,...}
```

### 5. Открыть порт

Если на VPS включён фаервол:

```sh
sudo ufw allow 28015/tcp
```

У облачных провайдеров порт ещё надо открыть в панели («Security Group», «Firewall
rules») — это самая частая причина, почему сервер виден на самой машине и не виден
снаружи.

### 6. Чтобы не падал при выходе из SSH

Самое простое:

```sh
sudo apt install -y tmux
tmux new -s osil
./build/bin/osil_server
# выйти из tmux, не убивая сервер: Ctrl+B, затем D
```

По-взрослому — службой systemd. Файл `/etc/systemd/system/osil.service`:

```ini
[Unit]
Description=OSIL Survival server
After=network.target

[Service]
WorkingDirectory=/home/USER/OSIL-Survival
ExecStart=/home/USER/OSIL-Survival/build/bin/osil_server
Restart=always
User=USER

[Install]
WantedBy=multi-user.target
```

```sh
sudo systemctl daemon-reload
sudo systemctl enable --now osil
sudo systemctl status osil     # посмотреть, что запустился
journalctl -u osil -f          # смотреть лог живьём
```

### 7. Зайти из игры

В игре: главное меню → **ДОБАВИТЬ СЕРВЕР** → вписать `АДРЕС:28015` (например
`91.201.10.5:28015`) → **ГОТОВО** → выбрать строку в списке → **ИГРАТЬ**.

Кнопка **ОБНОВИТЬ** опрашивает все сервера из списка и показывает, сколько там игроков
и какой пинг.

## Способ 2. Свой компьютер — для игры по домашней сети

То же самое, но собирать на своей машине:

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --target osil_server -j
./build/bin/osil_server
```

Дальше нужен локальный адрес компьютера:

```sh
ip a | grep "inet 192"      # например 192.168.1.50
```

С телефона, который сидит в том же Wi-Fi, в игре добавляем `192.168.1.50:28015`.

Чтобы пустить друзей из интернета, придётся пробросить порт 28015 на роутере (NAT /
port forwarding) и знать свой внешний IP. Если провайдер выдаёт «серый» IP, проброс не
сработает — тогда только VPS.

## Вход в игру: закрытый бета-тест

Играть можно только под одним из четырёх ников: **Tester0, Tester5, Tester6,
AdminTester**. Список прошит и в клиенте (чтобы отказ был мгновенным), и на сервере
(чтобы его нельзя было обойти правкой клиента).

* Первый запуск: вписать ник и пароль, нажать **СОЗДАТЬ АККАУНТ** — сервер заведёт
  запись. Дальше вход по тому же паролю кнопкой **ВОЙТИ**.
* Пароль на сервере не хранится: лежит соль и SHA-256 от «соль+пароль» в файле
  `accounts.txt` рядом с сервером (в репозиторий он не попадает).
* Ник **AdminTester** — админ теста: крафт и магазин ему бесплатны, а стаки в рюкзаке
  раз в секунду добиваются до полного, то есть ресурсы бесконечны.
* Ник менять нельзя: аккаунт заводится один раз, и сервер не даст зарегистрировать
  занятый ник второй раз.

Аккаунты живут на **официальном сервере** (адрес ниже): именно он проверяет пароль,
поэтому для входа он должен быть поднят.

## Монеты и магазин

В окне крафта есть переключатель **МАГАЗИН**: за монеты там покупают сырьё — дерево,
камень, руду, металл, серу, порох, ткань, скрап. Монеты капают из ящиков на заправке
(5–15 за ящик), на первый вход выдаётся 500. У AdminTester монеты бесконечны.

## Дома, киянка и рейд

Деталь дома бывает трёх уровней: **дерево 100 прочности, камень 200, железо 400**.
Улучшают их **киянкой**: взять её в руки, навести на свою деталь и нажать «рука» —
за 40 камня дерево станет камнем, ещё за 40 металла камень станет железом. Удар киянкой
сносит свою деталь целиком, и шкаф для этого не нужен.

Аренда идёт материалом по уровню: за деревянную деталь платят деревом, за каменную —
камнем, за железную — металлом, по 10 в сутки за штуку. В шкафу три ячейки под них.

Дверь занимает проём 2 на 2 и открывается ТОЛЬКО хозяином дома: чужая заперта, её
остаётся ломать. На это и есть оружие рейда — **ракетница**: одна ракета снимает 100
прочности постройке и до 150 здоровья тем, кто рядом. Граната — 50 прочности,
винтовка бьёт по игрокам на 35 с любой дистанции.

## Официальный сервер

В списке серверов он стоит второй строкой сразу после одиночной игры и добавляется сам —
вписывать ничего не надо. Адрес: `https://osil-survival1.onrender.com`. Список
опрашивается автоматически при первом заходе в меню, так что видно, жив ли сервер и
сколько там народу.

## Способ 3. render.com — в один клик из репозитория

В корне репозитория уже лежат `Dockerfile` и `render.yaml`, ничего писать не надо.

1. Зайти на render.com, **New → Blueprint**.
2. Указать этот репозиторий и ветку.
3. Render прочитает `render.yaml`, соберёт образ и запустит сервис. Порт он выдаёт сам
   через переменную `PORT` — сервер её читает. Проверка живости идёт на `/`.
4. Имя сервера меняется переменной `SERVER_NAME` в настройках сервиса.
5. Открыв адрес сервиса в браузере (`https://имя.onrender.com`), вы увидите карточку
   сервера — значит, всё поднялось.
6. В игре: **ДОБАВИТЬ СЕРВЕР** → вписать имя сервиса без всего лишнего, например
   `osil-survival.onrender.com` → **ГОТОВО** → **ИГРАТЬ**. Клиент сам поймёт, что это
   облако, и пойдёт по https.

Про сам https: игра открывает его системными средствами — на Android через
`HttpsURLConnection`, в настольной сборке через OpenSSL. Своей криптографии в игре нет,
APK от этого не тяжелеет.

Что стоит помнить про бесплатный тариф Render: сервис засыпает после 15 минут без
запросов, и первый вход после простоя займёт полминуты, пока он просыпается. Мир при
засыпании теряется — постройки живут в памяти сервера.

## Команды в консоли сервера

Сервер читает команды прямо с клавиатуры, пока запущен:

| команда | что делает |
|---|---|
| `help` | список команд |
| `status` | имя, время, погода, тики, сколько игроков онлайн |
| `time 12` | поставить полдень |
| `weather rain 0.8` | включить дождь |
| `world` | параметры мира и доли биомов |
| `quit` | остановить сервер |

## Частые грабли

* **«сервер не отвечает» в игре.** Проверьте `http://АДРЕС:ПОРТ/` в браузере телефона.
  Не открывается — дело в фаерволе или в порте, а не в игре.
* **Долгий вход по доменному имени.** Клиент сначала пробует один вариант (облако —
  https, голый IP — http на 28015), и только потом второй. Чтобы не ждать, пишите адрес
  точно: `http://mydomain.ru:28015` или `https://имя.onrender.com`.
* **Постройки у всех в разных местах.** Разошёлся сид: в `config/server.cfg` должно быть
  `world.seed = osil`.
* **Игрок «висит» в списке после выхода.** Сервер выкидывает молчащих через 12 секунд —
  это нормально.
* **Постройки пропали после перезапуска сервера.** Так и есть: журнал правок пока живёт
  в памяти и на диск не сохраняется.
* **Урон по игрокам не проходит, дроп и упавшие деревья не видны.** Сервер старой
  версии: эти сообщения появились в протоколе 2. В списке серверов такая строка помечена
  «старая версия сервера» — сервис надо пересобрать из свежей ветки.

---

## Чего сервер пока не делает

* не проверяет движение игроков (клиент авторитарен для себя) — это будущая защита от
  читов;
* не сохраняет мир на диск;
* не синхронизирует инвентарь: ресурсы у каждого свои.

Устройство протокола — [docs/network.md](network.md).
